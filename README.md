# Student Profile Hub – Team 145

## About the Project

Student Profile Hub is a collaborative student portfolio website created using HTML and CSS.

It showcases student profiles, technical skills and contact information.

## Technologies Used

- HTML5
- CSS3
- Git
- GitHub

## Project Pages

- index.html – Homepage
- profile.html – Student profiles
- skills.html – Team skills
- contact.html – Contact information
